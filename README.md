# AI Design Lab 🌌

현대건설 워크이노베이션센터 AI 디자인랩 공식 웹사이트

## 주요 기능

- 🪐 인터랙티브 우주 테마 디자인
- 🎨 AI 갤러리 - ACE 멤버들의 AI 작품
- 📰 카드뉴스 - AI 트렌드 소식
- 📋 게시판 - 공지사항 및 활동 내역
- 🎮 Play Day - 격주 AI 실험 프로젝트
- 🆘 도와줘요 ACE! - AI 적용 지원 신청
- 📚 Playbook - 월간 AI 활용 가이드

## 기술 스택

- HTML5
- CSS3 (반응형 디자인)
- Vanilla JavaScript
- Canvas API (파티클 효과)
